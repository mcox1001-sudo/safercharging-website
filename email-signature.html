How to install it

  1. Gmail: Settings (gear) → See all settings → General → Signature → create/select one → click in the box → paste (Ctrl/Cmd + V) → Save changes.
  2. Outlook (new / web): Settings → Accounts → Signatures → New signature → paste → Save.
  3. Apple Mail: Mail → Settings → Signatures → create one, then paste. (Untick "Always match my default message font".)
Use Copy signature for a ready-to-paste signature. Use Copy HTML source only where a tool asks for raw HTML.
